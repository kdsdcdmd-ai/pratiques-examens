# Validation

Trois pratiques existantes conservées : Mirka sciences chapitre 1 (10 leçons, 60 questions), Cédric sciences (9 leçons, 87 questions), Cédric histoire industrialisation (12 leçons, 82 questions). Aucun contenu scolaire nouveau ajouté lors de cette migration.

Mirka : validation antérieure contre les pages 2 à 26 conservée. Calculs, réponses numériques et 12 développements vérifiés lors de la préparation initiale; les développements utilisent une autoévaluation avec corrigé, sans correction IA.

Les anciennes réserves de Cédric restent signalées dans leurs inventaires : 2 en sciences et 3 en histoire. Cette migration ne constitue pas une nouvelle validation exhaustive de ces sources historiques.

Pour tout nouvel examen : contrôler les sources réellement fournies, toutes les notions pertinentes, les questions, les réponses et les explications; refaire les calculs. Une source illisible ou ambiguë doit être signalée avant intégration, jamais devinée. L’ajout est refusé si la couverture est incomplète ou si l’attestation de validation des sources manque. L’attestation doit suivre une vérification réelle.

Les illustrations utiles sont incorporées dans chaque contenu : aucun accès aux fichiers sources ou au Mac n’est requis. Les originaux et les progressions personnelles ne sont pas publiés.
